# EXAMIS — Threat model

Method: STRIDE per trust boundary, mapped to OWASP ASVS 4.0 Level 2 (personal data plus official decisions). Status values: **Mitigated** (implemented and tested), **Partial**, **Open** (owner decision or infrastructure required).

## 1. Assets

| Asset                                                                                  | Sensitivity                          |
| -------------------------------------------------------------------------------------- | ------------------------------------ |
| Applicant identity data (name, mother's name, birth date, national ID, phone, address) | High: personal data                  |
| Uploaded documents (ID cards, certificates, photos)                                    | High                                 |
| Review decisions and their history                                                     | High: integrity of official outcomes |
| Staff accounts and roles                                                               | Critical: privilege                  |
| Audit trail                                                                            | High: accountability                 |
| Reference numbers / receipts                                                           | Medium: forgery risk                 |

## 2. Actors and trust boundaries

Applicant (authenticated, untrusted input) · Family member sharing an email · Reviewer / Supervisor / Administrator / Auditor · Anonymous internet user · Automated bots · Infrastructure providers (hosting, mail/SMS, object storage) · Malicious insider with a staff account.

Boundaries: browser ↔ web tier (HTTPS); web tier ↔ PostgreSQL / Redis / object storage; queue worker ↔ external providers; service worker ↔ page.

## 4. Accepted residual risks (owner sign-off required)

1. `style-src 'unsafe-inline'`: Radix UI and the toast library set inline styles at runtime. Scripts remain nonce-only. Risk: CSS-based data exfiltration requires an HTML injection point, and none is known.
2. Structural scanning is not antivirus. **Must** be replaced or complemented with an AV engine before production.
3. An administrator who hands over a one-time link could use it first, because no mail service delivers it directly (ADR-0011).
